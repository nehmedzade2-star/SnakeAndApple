# Snake and Apple

Sadə Windows Forms ilan oyunu. Layihə .NET 8 Windows üzərində işləyir.


## Oyun qaydaları
- İlan ox düymələri və ya WASD ilə idarə olunur.
- Alma yeyildikdə xal artır və ilan uzanır.
- Hər yeni obyekt random olaraq alma və ya bomba olur.
- Obyekt təxminən 5 saniyə ekranda qalır, sonra yenisi çıxır.
- Alma yedikcə ilanın hərəkət sürəti artır.
- Bombaya toxunanda və ya ilan divara/özünə dəyəndə oyun bitir.
- Oyun bitdikdən sonra Enter ilə yeni oyun başlatmaq mümkündür.

## Açmaq
Visual Studio 2022-də `SnakeAndApple.csproj` faylını açın. .NET 8 SDK və Windows Forms workload tələb olunur.
